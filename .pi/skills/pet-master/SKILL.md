# 珍兽大师（pet-master）

数据来源：`PET_SYSTEM.md`（实测）+ `GOAL.md` 繁殖踩坑记录。
**核心事实：角色战力 = 自身战力 + 出战珍兽战力。** 所以「喂出战珍兽」是直接涨战力。

## 1. 喂经验的 ROI（这是最重要的一条）

| 投入 | 产出 |
|---|---|
| 4000 万经验 → 喂出战珍兽 | **+7,329 战力**（实测） |
| 同等经验 → 升珍兽技能 | 门槛 2.46 亿/级 → 几乎为 0 |
| 同等经验 → 喂暗器 | Lv.42 升 43 级要 16M，每级仅 +27 战力（约 1/10） |
| 同等经验 → 喂不出战的珍兽 | **0 战力**（历史踩坑：喂了 4000 万给松鼠，全浪费） |

规则：
1. 经验只喂**出战中**的珍兽
2. 一公一母都到 30 级后，经验全喂战力最高那只
3. 双倍经验（天灵丹）必须先吃满 —— 单批经验 4.1M → 14.6M

## 2. 资质与品质

```
资质 average = 四项资质相对模板百分比的平均值
品质：普通(灰) / 优秀(蓝) / 杰出(紫) / 完美(红)
变异形态：BABY 91~119%  |  MUTANT 164~197%
```

MUTANT 是唯一的数量级跃升。榜上 10 只 MUTANT，资质 164~197%。

## 3. 繁殖（寄托）流程 —— 踩过的坑全在这

```
前提：30 级及以上 + 从未繁殖过 + 一公一母
地点：苏州 mapId 5，云飘飘（其他图报「请到苏州云飘飘处办理」）
状态：必须先 COMBAT_STOP + 不在试炼中
```

实测规则：
- **同时只能有 1 份寄托**（第二份报「已有一份有效寄托」）→ 只寄托 1 只，另一只留身上当配对源
- 栏位满（含繁殖预留位）时不能寄托/孵化 → 先放生最低资质未出战宠
- 寄托后 1 小时可取二代
- `claim` 要 petId；`hatch` 可能报「道具不存在或数量不足」（可能 claim 只给蛋，要 hatch 才出宠）
- 领取必须先 `ENTER_MAP 5`，否则永远报「请到苏州云飘飘处办理」
- 领取失败：没领到 → 5 分钟重试；领到但没孵出 → 2 分钟重试

```js
PET_COMMAND { action:'deposit', petId }    // 寄托
PET_COMMAND { action:'claim', petId }      // 领取（在苏州）
PET_COMMAND { action:'hatch', ... }        // 孵化
```

拿到二代第一件事：`PET_COMMAND {action:'appraise', petId}` 看 `pet.form`
→ MUTANT：立刻 summon 出战 + 全量喂经验
→ BABY：继续喂原来那只

## 4. 技能书（15 种，itemId 980200~980214）

| id | 技能 | 类型 |
|---|---|---|
| 980200/980201 | 猛击 / 痛击 | 单体 160% |
| 980202 | 连击 | 两段 65% |
| 980203/980204 | 寒冰咒 / 烈火咒 | 内攻结算元素伤 |
| 980205 | 吸血 | 回 15% 伤害 |
| 980206 | 蛮力 | 自身外攻 +15%×资质 |
| 980207 | 法魂 | 自身内攻 +15%×资质 |
| 980208 | 迟钝 | 自身生命 +15%×资质 |
| 980209 | 憨厚 | 双防 +15%×资质 |
| 980210 | 借力 | **主人**外攻 +15%×资质 |
| 980211 | 凝神 | **主人**内攻 +15%×资质 |
| 980212 | 强身 | **主人**生命 +3.75%×资质 |
| 980213 | 反震 | 反射 15% |
| 980214 | 共生 | 自损 50% 血，回主人 18.75% |

- 技能上限 4 个，满了再打 → **随机覆盖已有技能**
- 接口：`PET_COMMAND { action:'book', petId, bagItemId }`
  （`USE_ITEM` 报「无法直接使用」，`action:'learn'` 报「未知珍兽操作」）
- 内外攻不匹配会报「该珍兽不能学习此技能」：凝神/法魂是内攻，外攻宠（extAtk>0, intAtk=0）学不了

推荐搭配：
```
外攻宠（螳螂）：蛮力 + 借力 + 强身 + 连击/猛击
内攻宠（松鼠）：法魂 + 凝神 + 强身 + 烈火咒
```
「给主人的三个」（借力/凝神/强身）永远优先。

## 5. 鉴定两种，别搞混

```
① 品质鉴定  action:'appraise'  1000 金币   只评品质，不改资质，无风险 → 每只都做
② 资质重刷  1 个金刚砂          重掷内外工资质，可能变低 → 高风险，高资质宠别刷
```

根骨提升：成功 +1，**失败 −1 级并重算四项资质/品质/战力**。攒够根骨丹再动手。

## 6. 何时刷蛋

```
玄武岛·外滩 mapId 20080  req1
击杀成年珍兽 → 珍兽蛋 → 背包使用孵化
```

判断：
- 栏位有空位 + 没有 MUTANT → 值得刷
- 历史：230+ 杀全 BABY → 刷蛋**不是** MUTANT 的可靠来源，繁殖才是
- 想学内攻技能书（凝神/法魂）但没内攻宠 → 刷蛋拿松鼠类

## 7. 放生红线

`core/redlines.mjs` 的 `assertNotBestPet` 会拦：最高资质个体永不放生。
放生要 `release` + `confirm:true`（只发 release 报「请收回并解锁」）。

## 8. 速查

```js
PET_COMMAND { action:'list' }                       // 全部珍兽 + activePetId + capacity + books
PET_COMMAND { action:'summon', petId }              // 出战（战力立即变化）
PET_COMMAND { action:'feed', petId, amount }        // amount 必须正数
PET_COMMAND { action:'lock', petId }                // 防误放生
PET_COMMAND { action:'release', petId, confirm:true }
```
⚠️ 参数名是 `petId`，不是 `id` / `petUid`。
⚠️ 珍兽操作要求不在战斗/试炼中 → 先 `COMBAT_STOP`。
