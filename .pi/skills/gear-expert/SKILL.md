# 装备专家（gear-expert）

数据来源：`GEAR_RESEARCH.md`（2026-11-14 实测）+ `core/lib-value.mjs`。
所有结论都有实测依据，**不要凭感觉覆盖**。

## 1. 一句话判据

> **战力公式 ≠ 实战能力。** 战力只算属性加权和，漏掉了实战最值钱的三样：
> 套装 `all_atk%`、洛神图元素倍率、防御减伤曲线。

## 2. 属性权重（`core/lib-value.mjs` 的 W 表）

| 属性 | 战力系数 | 实战权重 | 说明 |
|---|---|---|---|
| extAtk / intAtk | 4 | 4.0 | 主力输出，收益递减 |
| extDef / intDef | 3 | **4.5** | 减伤实测比战力评估更值钱 |
| hp | 0.3 | **0.9** | 生存，当前难度非瓶颈 |
| mp | 0.2 | 0.2 | 忽略 |
| critRate / precision | 5 | 5.0 | 与公式一致 |
| critDef / avoidance | 3 | **2.0** | 实战收益低于评估 |
| fireAtk / poisonAtk | 2 | **4.0** | 洛神图 +20% 放大 |
| iceAtk / holyAtk | 2 | **−2.0** | 洛神图 −35% 惩罚，**绝对不要** |
| iceDef/fireDef/poisonDef/holyDef | 1.5 | 1.5 | 中性 |
| 套装 all_atk | **0** | 130 分/1% | 战力公式完全不计 |

**基材 ×1.6、附加/鉴定 ×1.0** —— 因为强化和星级只乘 `baseStats`，
不乘 `extraStats`。挑装备先看基材。

## 3. 洛神图（唯一被动，已满级）

```
火伤 +20%   毒伤 +20%
冰伤 −35%   玄伤 −35%   ← 惩罚
```

→ 装备上的冰攻 / 玄攻是**负资产**。看到冰/玄直接降权，别为了「战力数字」穿。

## 4. 防御的真实价值

```
减伤率 ≈ 防御 / (防御 + 5000)
```

| 防御 | 减伤 | 每 +100 防御边际 |
|---|---|---|
| 2000 | 28.6% | +1.40% |
| 3000 | 37.5% | +1.25% |
| 4000 | 44.4% | +1.11% |
| 5000 | 50.0% | +1.00% |

→ 3000~5000 区间性价比最高。超过 5000 后收益明显递减，转投攻击。

## 5. 套装凑件优先级

`all_atk +20%` 的 4 件套共 12 个，是当前唯一能大幅跃升的路径。

| 套装 | 槽位 | 4 件效果 |
|---|---|---|
| 般若 | 5,2,10,9 | all_atk +20%, ext_atk +650, hp +3750, ext_def +300 |
| 控鹤 | 5,2,10,9 | all_atk +20%, int_atk +400, hp +2675 |
| 锁魂 | 2,6,8,7 | all_atk +20%, int_atk +680, hp +2500 |
| 纯阳 | 5,2,10,9 | all_atk +20%, int_atk +350, hp +2250 |
| 神龙 | 2,6,8,7 | all_atk +20%, ext_atk +630, hp +2250 |
| 少阳 | 2,6,8,7 | all_atk +20%, ext+int +175, hp +2250, precision +180 |
| 八荒 / 地火 / 八卦 | 5,2,10,9 | all_atk +20% + 各系 |
| 韦陀 / 四象 / 抽髓 | 1,6,9,7 或 1,2,4,10 | all_atk +15% |

判断顺序：
1. 已穿件里哪个套装件数最多 → 优先补齐那套（3/4 差 1 件 > 0/4 差 4 件）
2. 差 1 件时，看商城 / 掉落图，为这一件专门切图
3. 御赐套装（万灵石兑换）**已实测净亏**，不要再换

## 6. 强化 / 星级 / 熔炼门槛（实测，别再试错）

```
强化倍率 ENH = {1:10,2:20,3:30,4:45,5:65,6:90,7:120,8:155,9:195}%  只乘 baseStats
强化精华必须与装备等级匹配：低级精华只强化 req<40 的装备（我们 12 件 req50+）
熔炼（升星）只对武器开放，门槛「双资质 > 1500」
  → 资质 = appraisalStats.extScore / intScore
  → 已鉴定武器可「重新鉴定」（1 个金刚砂），会重掷资质，有升有降
金刚砂 = 元宝商城 300 元宝/个（天工坊）→ 元宝 0 时此路堵死
```

## 7. 判断树（换装/卖装）

```
新装备到手
├─ slotType 是什么槽？
│   └─ slot9（腰带）基材只有 avoidance → 不值得投入鉴定/强化
├─ 含冰攻/玄攻？ → 按 −2.0 权重算，通常不穿
├─ itemValue(新) vs 同槽当前件
│   ├─ 差值 < 50 → 不动（波动级别）
│   └─ 差值 ≥ 50 → 用 swapDelta() 连套装一起算，delta>0 才换
└─ 卖出前必须过 core/redlines.mjs：
    assertSafe({action:'SHOP_SELL', itemId, item, owned})
    → 同槽前 2 强直接 throw
```
